# HoudiniCommon

Shared Houdini tools for all local Houdini versions.

## Folders

- otls: HDA/OTL files
- toolbar: Shelf files
- scripts: Houdini scripts
- icons: Custom icons
- python: Shared Python modules, added through HOUDINI_PATH
- packages: Package JSON files used by Houdini user folders
- docs: Notes and usage documentation
- backups: Manual backups before tool changes

## Install

Run install_houdini_common.ps1 after Houdini has created one or more Documents/houdiniXX.X folders.
